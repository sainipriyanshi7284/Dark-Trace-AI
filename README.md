# CYBERSENTINEL

A responsive enterprise cybersecurity dashboard for multi-agent network intrusion detection. The interface includes live network analytics, searchable event data, collaborative AI agent evidence, threat intelligence, incident investigation, and model performance reporting.

## Features

- Six fully routed dashboard pages
- Responsive desktop and mobile navigation
- Interactive Recharts visualizations
- Searchable and filterable network event table
- Multi-agent inference and evidence workflow
- Interactive incident response controls
- Realistic, clearly labeled mock security data

## Tech stack

React 19, TypeScript, Vite, Tailwind CSS v4, React Router, Recharts, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
```

All data is frontend-only mock data. This project does not include a backend, database, API, or machine-learning model.
